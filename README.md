# AscensionUnlockMod

`AscensionUnlockMod` adds an `Ascension` button on the main menu so you can set ascension unlock level per character.

## Download

1. Open this repository's `Releases` page.
2. Download `AscensionUnlockMod-v1.0.0.zip` from release `v1.0.0`.

## Install (Manual)

1. Close Slay the Spire 2.
2. Extract `AscensionUnlockMod-v1.0.0.zip`.
3. In Steam, right-click `Slay the Spire 2` -> `Properties` -> `Installed Files` -> `Browse`.
4. In the game folder that opens, create a `mods` folder if it does not exist.
5. Drag the extracted `AscensionUnlockMod` folder into `mods`.
6. Confirm these files exist in `mods/AscensionUnlockMod`:
   - `AscensionUnlockMod.dll`
   - `AscensionUnlockMod.pck`
7. Launch Slay the Spire 2. If prompted to enable mods, accept and relaunch.
8. In-game, open `Settings` -> `General` -> `Mods` and make sure `AscensionUnlockMod` is enabled.

## Use

1. From the main menu, click `Ascension`.
2. Set per-character ascension unlock levels (`0-10`) and click `Apply`.
